# Telegram-бот знакомств

Минимальный Telegram-бот для знакомств: анкеты, карточки, лайки, взаимные совпадения, жалобы и блокировка.

## Возможности

- Создание и обновление анкеты: возраст 18+, имя или псевдоним, город, пол, кого ищет пользователь, описание и необязательная фотография.
- Просмотр новых анкет, лайк и пропуск.
- Уведомление обоим участникам при взаимном лайке.
- Telegram username передаётся при совпадении только если владелец анкеты разрешил его показывать.
- Жалоба и блокировка из карточки.
- Команда `/delete` удаляет анкету, лайки и блокировки пользователя.
- Локальный запуск использует SQLite. Для постоянного размещения задайте PostgreSQL `DATABASE_URL`.

## Локальный запуск в PowerShell

Нужен Python 3.11 или новее и токен, созданный через `@BotFather`.

```powershell
cd путь\к\gift-market-dating-bot
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN = "ВСТАВЬ_ТОКЕН_БОТА"
python main.py
```

Не публикуйте токен и не отправляйте его в чат. Если токен уже случайно раскрыт, отзовите его у `@BotFather` и создайте новый.

## Размещение на EthioDeploy

1. Поместите файлы проекта в отдельный GitHub-репозиторий, например `telegram-dating-bot`.
2. В EthioDeploy создайте отдельный проект из этого репозитория. Не подключайте его вместо проекта существующего бота.
3. Выберите тип сервиса **Background Worker**: бот использует long polling и не принимает HTTP-запросы.
4. Добавьте секрет `TELEGRAM_BOT_TOKEN` в переменные окружения проекта.
5. Подключите PostgreSQL и проверьте, что его `DATABASE_URL` доступен приложению.
6. Дождитесь успешного запуска и откройте логи.

У одного токена бота должен быть только один активный polling-процесс. Перед запуском на EthioDeploy остановите локальную копию, иначе Telegram может вернуть ошибку `409 Conflict`.

На бесплатном EthioDeploy фоновый процесс не засыпает, но его память и CPU расходуют квоту: сейчас указаны 50 GB-hours памяти и 20 CPU-hours в месяц. Превышение лимитов может приостановить проект, поэтому бесплатный тариф подходит для пробного запуска, но не обещает постоянную работу при любой нагрузке. Проверьте актуальные лимиты в панели и в [инструкции EthioDeploy](https://ethiodeploy.com/deploy/telegram-bot).

## Перед запуском для реальных пользователей

Это MVP, а не готовый сервис знакомств. Сейчас жалобы сохраняются в базе, но автоматической модерации и панели администратора нет. Перед публичным запуском добавьте контакт модератора, процесс рассмотрения жалоб и понятную политику конфиденциальности. Фотографии хранятся в Telegram, а бот сохраняет их `file_id`; анкеты и отметки хранятся в подключённой базе данных.
